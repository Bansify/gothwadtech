# Branding

## The mark

A white disc carrying a blue **B** on the brand blue `#0494F4` plate. This is the official
Bansify logo; it is not redrawn anywhere.

**Master set:** `Bansify/storage` → `brand/bansify-official-logo/`
(`android/`, `androidtv/`, `ios/`, `macos/`, `tvos/`, `watchos/`, `web/`, `play-store/`,
plus a README with the usage rules). Every asset on this site is generated from
`web/icon-512.png`.

## What this site ships

| File | Size | Generated by |
|---|---|---|
| `assets/brand/logo.png` | 512×512 | exact artwork |
| `assets/brand/og-image.png` | 512×512 | exact artwork (matches the declared OG size) |
| `favicon-16x16.png`, `favicon-32x32.png`, `favicon-48x48.png` | 16/32/48 | downscaled |
| `favicon.ico` | 16+32+48 | multi-size ICO |
| `apple-touch-icon.png`, `apple-touch-icon-180x180.png` | 180 | full-bleed plate, mark inset |
| `icon-192x192.png`, `icon-512x512.png` | 192/512 | downscaled |
| `assets/icons/icon-{48,144,192,384,512}.png` | — | downscaled |
| `assets/icons/icon-*-maskable.png` | — | full-bleed plate, mark at 72% (safe zone) |
| `logo.svg` | 512 | vector container embedding the exact artwork |

## Rules

- Keep `#0494F4`. Do not recolour, gradient or outline the mark.
- Do not stretch, rotate or add effects; scale the supplied PNGs.
- Keep clear space of at least the width of the "B" around the mark.
- Maskable icons need the mark inside the inner 80%; the launcher/store crops the rest.
- The wordmark in the navbar is text, not part of the image.

## Changing the logo later

1. Replace the master set in `Bansify/storage`.
2. Regenerate the files in the table above from the new `web/icon-512.png`
   (Pillow: resize, plus a full-bleed composite for the maskable/Apple variants).
3. Rebuild `logo.svg` as an `<svg>` with an `<image>` element carrying the PNG as base64.
4. Update the OG meta width/height if the new social image is not 512×512.
